# Mobile Sales Dashboard – Power BI

An interactive Power BI dashboard analyzing mobile phone sales performance across brands, cities, and time periods.

## Overview

This dashboard tracks key sales metrics for mobile phone retail data, helping identify top-performing brands, regional sales trends, and customer behavior patterns.

## Tools Used
Power BI Desktop
Power Query (data cleaning & transformation)
DAX (custom measures for KPIs)
## Key Metrics Tracked
Total Sales & Total Quantity Sold
Number of Transactions
Average Sale Value
Customer Ratings
## Features
KPI Cards – Quick view of total sales, quantity, transactions, and average metrics
Map Visualization – City-wise sales distribution
Trend Analysis – Sales trends over time using line and area charts
Brand & Model Comparison – Clustered column chart comparing sales by brand/model
Payment Method Breakdown – Pie and funnel charts showing payment preferences
Detailed Data Table – Drill-down view of raw sales records
Interactive Filters – Slice data by Brand, City, Date, and Payment Method
## Data Fields

Brand, Mobile Model, City, Date, Payment Method, Customer Ratings, Total Sales, Total QTY, Transactions
